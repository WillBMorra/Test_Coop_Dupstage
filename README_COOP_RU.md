# DubStage — Co-op

## Запуск

1. Установите зависимости через `Setup.bat`.
2. Запустите `Start DubStage.bat`.
3. Для кооператива запустите DubStage **два раза** (для теста на одном ПК).

## Host

1. Выберите Dub-Pack в главном меню.
2. Нажмите `Koop`.
3. Введите имя и порт (по умолчанию `8765`).
4. Нажмите `Host`.
5. Дождитесь подключения игроков.
6. Нажмите `START`.

После `START` все клиенты получают выбранный Host'ом pack и переходят на сцену.

## Игрок

1. Нажмите `Koop`.
2. Выберите `Join`.
3. Для теста на одном ПК используйте `127.0.0.1`.
4. Введите тот же порт.
5. Введите своё имя.
6. Нажмите `Join`.

## Очередь

После старта **только Host управляет очередью**.

Кнопка `Wer spricht?` позволяет выбрать конкретного игрока для текущей реплики.
Только выбранный игрок получает активную кнопку `Aufnehmen`.

После записи клиент отправляет WAV Host'у по TCP. Host синхронизирует запись с остальными участниками.

Клиенты не могут самостоятельно переключать реплики.

## Тест на одном компьютере

Откройте два окна:

- окно 1: `Koop -> Host -> START`
- окно 2: `Koop -> Join -> 127.0.0.1`

Нажатие `START` должно происходить **в окне Host** после появления второго игрока.
