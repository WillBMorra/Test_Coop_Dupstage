# DubStage Co-op — полная схема Host → общая дорожка

## Как запускать

1. На всех компьютерах распакуйте один и тот же DubStage и один и тот же Dub-Pack.
2. Запустите `Start DubStage.bat`.
3. На компьютере Host выберите Dub-Pack и микрофон.
4. Откройте `CO-OP` → `Host` → `CONNECT / HOST`.
5. На компьютере игрока откройте `CO-OP` → `Join`, укажите IP Host и порт `8765` → `CONNECT / HOST`.
   - На одном компьютере для теста используйте `127.0.0.1`.
6. Host нажимает `START`.
7. У всех участников открывается одна и та же сцена.
8. Host нажимает `Choose speaker` и выбирает игрока.
9. Только выбранный игрок может нажать `Record`.
10. После записи WAV отправляется Host'у.
11. Host помещает WAV в `line.take` нужной реплики и рассылает его участникам.
12. После всех реплик Host нажимает `Done`/завершает сцену и экспортирует результат.

## Итоговая дорожка

Все реплики находятся на Host в одном `pack.lines`, каждая в своём `line.take`.
Финальный `ds.render_dub(pack)` использует эти записи, поэтому экспорт Host'а содержит голоса всех игроков в одной общей дорожке/миксе.

## Важно

- Все участники должны иметь одинаковый Dub-Pack локально.
- Сетевой режим передаёт только готовые записи, а не поток микрофона.
- Для теста на одном ПК запустите DubStage два раза и подключите второй экземпляр к `127.0.0.1:8765`.
- Для LAN используйте локальный IPv4 Host-компьютера и разрешите Python/DubStage в Windows Firewall.
