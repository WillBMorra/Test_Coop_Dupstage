# DubStage Co-op — клиент без пака

В этой версии пак нужен только Host'у.

1. Host выбирает Dub Pack.
2. Host запускает Co-op и нажимает START.
3. Клиент подключается и не обязан иметь этот пак.
4. Host автоматически передаёт клиенту копию пака по TCP.
5. Клиент распаковывает его во временную папку.
6. После получения пака клиент загружает сцену и может участвовать в дубляже.

Пак не устанавливается в `packs/` клиента и удаляется системой после завершения/очистки временных файлов.
